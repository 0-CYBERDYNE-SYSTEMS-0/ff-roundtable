## Product Requirements Document (PRD) for Farm Friend Roundtable

### Executive Summary
**Farm Friend Roundtable** is an innovative AI-powered chat application designed to empower farmers and agricultural experts through interactive, multi-expert discussions. By leveraging OpenRouter’s diverse AI models, the app offers a unique roundtable of 4-8 AI experts, each with specialized roles, who interact with users and each other. The app features an unconventional, engaging user interface (UI) resembling a top-down roundtable, inspired by the Simon Says game. Key features include file uploads, rich text display, Markdown export of conversations, and a sidebar for summarizing key insights. The application will be monetized through a $10 monthly subscription via Stripe, and one expert will always have the ability to create and provide downloadable files (e.g., documents, code) upon user request.

### Product Vision
**Farm Friend Roundtable** aims to revolutionize agricultural discussions by providing farmers with access to a diverse set of AI experts that can collaborate, refine ideas, and provide actionable insights. The app’s unique roundtable format fosters a collaborative environment where farmers can engage with multiple perspectives, leveraging smaller AI models to achieve productivity gains through interaction and revision. The app’s architecture is designed to be scalable, secure, and user-friendly, with a focus on natural language interaction and ease of use.

### Target Audience
- **Primary Users**: Farmers and agricultural professionals seeking expert advice and collaborative discussions.
- **Secondary Users**: Agricultural researchers, students, and enthusiasts interested in AI-driven insights.

### Key Features
1. **Roundtable of AI Experts**
   - Users can select 4-8 AI experts from OpenRouter’s model library, each with distinct agricultural roles (e.g., soil expert, crop yield analyst).
   - Experts interact with users and each other, refining ideas and providing collaborative insights.

2. **Unconventional User Interface**
   - A top-down roundtable view, with experts visually seated around a table, creating an immersive and engaging experience.
   - Rich text display supporting tables, code blocks, bullet points, and more.

3. **File Upload and Attachment Handling**
   - Users can upload files (e.g., reports, images) to be included in the conversation context.
   - Experts can reference uploaded files in their responses.

4. **File Creation Tool**
   - One designated expert (e.g., “FileCreator”) can generate files (e.g., `.txt`, `.pdf`, `.py`) based on user requests.
   - Files are generated, stored temporarily, and provided via download links in the chat.

5. **Web Search and Imagery Generation**
   - One or two experts have access to the Perplexity API for internet searches, providing sourced information.
   - One expert uses Google Gemini Flash 2.0 (via OpenRouter) to generate agricultural imagery upon request.

6. **Moderator AI**
   - Manages conversation summaries and context lengths, ensuring critical information is saved.
   - Displays key insights and bullet points in a sidebar for quick reference.

7. **Markdown Export**
   - Users can export entire conversations as Markdown files for later use.

8. **Subscription Model**
   - A $10 monthly subscription via Stripe is required to access the app.
   - Subscription status is checked upon login, and non-subscribed users are redirected to the subscription page.

#### Backend

- **Database**: MongoDB for storing user data, conversation history, and subscription statuses.
- **File Handling**: Multer for managing file uploads.

- **Payment Processing**: Stripe API for handling subscriptions and payments.

#### AI Integration
- **AI Models**: OpenRouter API for accessing a wide range of models, including free and premium options.
- **Web Search**: Perplexity API (via OpenRouter) for internet searches with citations.
- **Imagery Generation**: Google Gemini Flash 2.0 (via OpenRouter) for generating agricultural images.
- **Custom Instructions**: Each expert will have tailored system messages defining their roles and behaviors.

#### Additional Tools
